# Beacon Arcade

공개 난수 비컨 기반 미니게임 실험 프로젝트입니다. 현재는 베팅 없이 결과 생성·검증 흐름을 확인하는 **1분 양궁 프로토타입**을 개발합니다.

## 양궁 프로토타입

게임 규칙과 범위는 [`docs/양궁-프로토타입-명세.md`](docs/양궁-프로토타입-명세.md)를 참고하세요.

## 실행

Node.js가 설치되어 있으면 테스트는 `npm test`로 실행합니다. 정적 페이지는 저장소 루트에서 다음 명령으로 제공합니다.

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

그다음 `http://127.0.0.1:8765/`를 엽니다. NIST Beacon을 조회하려면 브라우저에서 인터넷에 접속할 수 있어야 합니다. 이 프로토타입은 브라우저 시계를 사용하므로 금전 보상이나 공식 경쟁에 사용할 수 있는 공정성 시스템이 아닙니다.
